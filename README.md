# PS2 na TV

Página web em tela cheia com o emulador **Play!** (PlayStation 2) e suporte a controle (Gamepad API), feita para abrir no navegador de uma TV.

- O jogo **não** está hospedado aqui. Você escolhe o arquivo (.iso/.cso/.chd) do seu próprio jogo no aparelho; ele é lido localmente e nunca é enviado.
- Emulador: [Play!](https://github.com/jpd002/Play-) por Jean-Philip Desjardins, licença BSD-2 (ver `LICENSE-Play.txt`). Build web original: playjs.purei.org.
- `coi-serviceworker` (MIT) habilita SharedArrayBuffer no GitHub Pages.

## Controle
| Controle | PS2 |
|---|---|
| A / ✕ | ✕ |
| B / ◯ | ◯ |
| X / ▢ | ▢ |
| Y / △ | △ |
| LB / RB | L1 / R1 |
| LT / RT | L2 / R2 |
| Analógicos / D-pad | Analógicos / D-pad |
| Start / Select | Start / Select |
